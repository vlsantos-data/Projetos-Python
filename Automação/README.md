🚀 Projetos de Automação e Engenharia de Dados
Bem-vindo ao meu repositório de desenvolvimento! Este espaço foi criado para documentar minha jornada e evolução na programação com Python, servindo como um laboratório prático para o aperfeiçoamento da minha lógica de programação e como portfólio para minha futura atuação na área de Dados e Engenharia.

📌 Objetivo do Repositório
O foco aqui é ir além da sintaxe. Utilizo estes projetos para:

Aperfeiçoamento de Lógica: Exercitar o raciocínio algorítmico estruturado, essencial para minha formação em Engenharia da Computação.

Automação de Processos (RPA): Criar soluções que eliminam tarefas repetitivas, integrando bibliotecas como PyAutoGUI e ferramentas de produtividade.

Manipulação de Dados: Aplicar Pandas e SQL para extrair, tratar e analisar grandes volumes de informações, transformando dados brutos em indicadores estratégicos (ETL).

📂 Destaques deste Repositório
1. Automação de Relatórios de Vendas (RPA)
Um pipeline completo que simula um desafio real de mercado:

Extração: Navegação automatizada via navegador para download de bases de dados.

Processamento: Uso de Pandas para calcular faturamento e volumetria de vendas.

Comunicação: Integração automática com Gmail para envio de relatórios formatados para a diretoria.

2. Utilidades e Ferramentas Práticas
Projetos voltados para facilitar o dia a dia e explorar diferentes bibliotecas Python:

Gerador de QR Code Personalizado: Uso das bibliotecas qrcode e Pillow para criação de códigos dinâmicos com suporte a estilos e logos.

🛠️ Tecnologias Utilizadas
Linguagem: Python 3.x

Bibliotecas: Pandas, PyAutoGUI, Pyperclip, Openpyxl, Qrcode.

Ambiente: VS Code / Jupyter Notebooks.

👨‍💻 Sobre Mim
Sou aluno de Engenharia da Computação na ESAMC, focado em construir soluções que unam eficiência técnica e inteligência de dados. Acredito que a automação é a chave para a produtividade moderna e utilizo este repositório para testar novos conceitos de infraestrutura e backend.

💡 Como utilizar:
Clone o repositório.

Instale as dependências: pip install pandas pyautogui openpyxl qrcode[pillow].

Certifique-se de ajustar as coordenadas do PyAutoGUI de acordo com a resolução da sua tela.
